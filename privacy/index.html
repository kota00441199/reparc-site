プライバシーポリシー

制定日：2026年10月12日

1. はじめに

中山弘太（以下「運営者」）は、筋トレ記録アプリ「RepArc」（以下「本アプリ」）での利用者の情報の取り扱いについて、このプライバシーポリシーを定めます。

本アプリは、アカウントを作らなくても使えます。その場合、記録はお使いの端末の中だけに保存され、運営者に送られることはありません。

2. 取得する情報

本アプリが扱うのは、利用者が自分で入力した情報だけです。位置情報、連絡先、写真、マイクの音声、広告用の識別子は取得しません。

情報内容端末に保存クラウドに保存
アカウント情報メールアドレス、パスワード（暗号化して保存）ログイン状態のみアカウントを作った場合
トレーニング記録トレーニング名、種目、重量、回数、距離、時間、セットの結果、きつさ（RPE）、メモ、日時、休憩時間すべてログイン中のみ
プロフィール名前（ニックネーム可）、体重、身長、トレーニング目標、トレーニング開始日入力した場合ログイン中のみ
体重の記録日付と体重入力した場合ログイン中のみ
イベント大会やMAX Dayなどの名前と日付入力した場合ログイン中のみ
自分で追加した種目種目名と部位入力した場合ログイン中のみ
アプリの設定重量の単位、言語、休憩タイマーの設定などすべてログイン中のみ

体重や身長は健康に関わる情報です。入力は任意で、入力しなくても本アプリの記録機能は使えます。

3. 利用目的

取得した情報は、次の目的にだけ使います。

  • トレーニング記録の保存と、自己ベスト・グラフ・履歴などの表示
  • クラウドへのバックアップと、機種変更時などの復元
  • ログイン、パスワードの再設定、アカウントの削除など、アカウントの管理
  • アカウントに関する重要なお知らせや、お問い合わせへの回答

広告の配信、行動の追跡（トラッキング）、データの販売には使いません。

4. 保存場所と外部サービス

記録はまずお使いの端末の中に保存されます。ログイン中は、記録や設定を保存したときに、そのバックアップがクラウドにも自動で保存されます。

アカウントの管理とクラウドへの保存には、Supabase, Inc. が提供するサービス「Supabase」を使っています。データの保存先は日本（東京）にあるサーバーです。Supabaseでの情報の扱いは、同社のプライバシーポリシーに従います。

運営者は、次の場合を除き、利用者の情報を第三者に提供しません。

  • 利用者本人が同意した場合
  • 法令に基づいて開示を求められた場合
  • 上記のSupabaseのように、本アプリの運営に必要な範囲でデータの保管を任せる場合

広告やアクセス解析のサービスは使っていません。

5. 保存期間と削除

情報は、利用者が削除するまで保存します。削除は、すべてアプリの中から利用者自身で行えます。

操作削除されるもの
メニュー → アカウント → アカウントを削除するアカウント（メールアドレス）、クラウドのバックアップ、端末の記録
メニュー → アカウント → ログアウト → データも削除してログアウト端末の記録（アカウントとクラウドのバックアップは残ります）
メニュー → データの管理 → 全データを削除端末の記録
アプリの削除（アンインストール）端末の記録

アカウントを削除すると、元には戻せません。アプリを使えない場合は、「8. お問い合わせ」の連絡先へご依頼ください。運営者が削除します。

6. 利用者ができること

  • 記録の書き出し：メニュー → データの管理から、記録をバックアップファイルやCSVファイルとしていつでも書き出せます。
  • 記録の訂正と削除：アプリの中で、記録やプロフィールを直接変更・削除できます。
  • 通知の許可：休憩タイマーの終了を知らせるために通知を使います。通知は端末の中だけで作られ、運営者から送るものではありません。設定画面や端末の設定でいつでもオフにできます。
  • 開示などの請求：保存されている情報の開示、訂正、利用停止、削除を求める場合は、「8. お問い合わせ」の連絡先へご連絡ください。ご本人確認のうえ、対応します。

7. 安全管理と未成年の利用

クラウドとの通信は暗号化されています。クラウドのバックアップは、本人のアカウントでログインしたときだけ読み書きできます。同じ端末で別のアカウントにログインしても、前の利用者の記録がそのアカウントに保存されることはありません。

未成年の方がアカウントを作る場合は、保護者の同意を得てからご利用ください。
